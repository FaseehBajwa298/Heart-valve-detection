# 🫀 AI Heart Valve Disorder Detection

A comprehensive project for **AI-based Heart Valve Disorder Detection**, featuring a legacy frontend and a modern React-based application.

## 🎯 Project Overview

This project aims to develop an AI system for detecting heart valve disorders through advanced machine learning algorithms and echocardiogram analysis. It includes two main frontend implementations:

1.  **React Application (New)**: A modern, scalable, and responsive web app located in the `heart-valve-app/` directory.
2.  **Legacy Frontend**: The original HTML/CSS/JS implementation located in the `Frontend/` directory.

## 🚀 Quick Start (React App)

The main development focus is now on the React application.

1.  **Navigate to the React app directory:**
    ```bash
    cd heart-valve-app
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the app:**
    ```bash
    npm run dev
    ```

For detailed documentation on the React app, please refer to [heart-valve-app/README.md](./heart-valve-app/README.md).

## ✨ Features

### Modern React App (`heart-valve-app`)
- **Framework**: React + Vite + Tailwind CSS
- **Auth**: Context-based Authentication (Login/Signup/Logout)
- **UI**: Responsive design with medical aesthetics
- **Navigation**: Client-side routing with React Router

### Legacy Frontend (`Frontend`)
- **Tech**: HTML5, CSS3, Vanilla JavaScript
- **Features**: Basic authentication forms, password strength meter

## 🛠️ Technologies Used

- **Frontend**: React, Tailwind CSS, Vite
- **Legacy**: HTML5, CSS3, JavaScript
- **Version Control**: Git
